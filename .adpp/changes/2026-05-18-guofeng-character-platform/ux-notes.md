## 3. 页面级实现说明

### 3.1 首页

- Figma 参考：
  - 首页：https://www.figma.com/design/0oLoQWIykGOTIvvzeMsQan/%E7%A7%91%E7%A0%94%E7%AE%A1%E7%90%86%E5%B9%B3%E5%8F%B0?node-id=29-3917&t=yow0lQYCugEsx1ml-11
- 页面目标：
  - 让首次访问用户在 3-5 秒内理解“这是一个女性向国风角色生成平台”
  - 让用户快速感知平台的风格能力、案例质量和情绪价值
  - 把游客尽可能转化为“进入生成流程”的潜在用户
- 适用用户：
  - 游客
  - 已登录但尚未开始生成的用户
  - 分享回流的新用户
- 页面入口：
  - 直接访问站点根路径
  - 分享链接回流
  - 登录成功后回跳
- 页面出口：
  - 点击“立即生成”进入生成工作台
  - 点击风格卡片或情绪模板卡片带着预设条件进入生成工作台
- 页面信息结构：
  - 顶部导航：Logo、登录/用户入口、积分入口
  - 首屏 Banner：主文案、副文案、主 CTA、辅助 CTA
  - 风格展示区：4 个主要风格卡片，展示名称、风格说明、示意图
  - 示例角色区：按头像、梦女、小说女主、汉服写真、封面图分类展示
  - 情绪化模板入口：以更强的身份叙事组织模板
  - 信任补充区：免费次数、生成速度、支持参考图、可分享等卖点
- Banner 细节：
  - 主标题突出“国风角色”“梦女/OC”“一句话生成”
  - 副标题减少技术术语，强调低门槛和幻想表达
  - 主按钮固定为 `立即生成`
  - 辅助按钮可为 `看看案例`
- 风格展示区细节：
  - 每张卡片至少包含风格名、简短说明、代表性缩略图
  - 卡片可点击，点击后将风格参数带入生成工作台
- 示例角色区细节：
  - 首屏至少展示 6-8 个示例
  - 示例卡片可点开大图预览
  - 示例可标注风格或模板标签，但不展示过多技术参数
- 情绪化模板入口细节：
  - 模板文案以“幻想身份”命名，而不是纯功能名
  - 每个模板卡片包含标题、情绪短句、适用场景、进入生成按钮
- 默认态：
  - 首屏展示产品定位与主要风格
  - 案例图正常展示
- 加载态：
  - 案例区与模板区使用 skeleton 卡片
- 空态：
  - 无案例时展示占位案例和“即将解锁更多作品”
- 异常态：
  - 案例加载失败时显示“案例加载失败，请稍后再试”
  - 不影响用户继续进入生成流程
- 响应式要求补充：
  - 桌面端首屏可采用左文案右视觉主图
  - 移动端首屏改为单列，CTA 保持尽快可见
  - 情绪模板区在移动端应横向滑动或单列折叠
- 实现边界：
  - 首页不要求登录才能浏览
  - 首页不承载复杂业务逻辑，只承载转化和预设导流

### 3.2 生成工作台

- Figma 参考：
  - 生成工作台：https://www.figma.com/design/0oLoQWIykGOTIvvzeMsQan/%E7%A7%91%E7%A0%94%E7%AE%A1%E7%90%86%E5%B9%B3%E5%8F%B0?node-id=29-3195&t=yow0lQYCugEsx1ml-11
- 页面目标：
  - 帮助用户低门槛完成一次角色生成
  - 让参数选择过程足够清晰，不让用户产生“不会用”的挫败感
  - 在提交前让用户明确本次消耗的积分和结果方向
- 适用用户：
  - 首次生成用户
  - 已登录复用模板用户
  - 需要参考图和多参数生成的进阶用户
- 页面入口：
  - 首页 CTA
  - 首页风格卡/模板卡
  - 作品页“再次生成”
  - 分享回流后的新用户首跳
- 页面出口：
  - 提交成功后进入生成中状态页或结果承接页
  - 积分不足进入充值页
  - 未登录提交时拉起手机号验证码登录弹窗或独立页
- 页面布局建议：
  - 桌面端采用左右双栏
  - 左侧为输入与参数配置区
  - 右侧为预览说明、示例图、积分报价和注意事项
- PRD 枚举映射要求：
  - 本页所有可选项必须直接映射 PRD 中已确认的枚举，不允许实现时再自由发挥
- 核心区域：
  - Prompt 输入框
  - 推荐 Prompt / 一键灵感 / 随机灵感
  - 风格选择
  - 模板选择
  - 比例选择
  - 参考图上传
  - 质量档与积分报价
  - 立即生成按钮
- Prompt 输入区细节：
  - 输入框有示例占位文案
  - 显示字数计数
  - 支持一键插入推荐示例
  - 随机灵感可一键替换当前内容或追加到当前输入
  - 支持“润色”按钮，将当前输入发送到后端 Prompt 润色接口，成功后用扩展后的 Prompt 替换输入框
  - 润色过程中按钮展示加载态并禁用重复点击；空输入、超长输入、未登录和模型不可用都需给出可恢复提示
  - 必须展示或可感知当前字数区间规则：
    - `prompt_short`：`1-40` 字
    - `prompt_standard`：`41-120` 字
    - `prompt_long`：`121-300` 字
    - `prompt_over_limit`：`>300` 字不可提交
- 推荐 Prompt 区细节：
  - 至少提供以下示例：
    - `盛唐时期华贵贵族女子`
    - `仙侠白衣少女`
    - `新中式冷艳女性`
  - 推荐 Prompt 以可点击标签或卡片方式展示
- 一键灵感区细节：
  - 点击后生成新的随机 Prompt
  - 用户可选择“替换当前输入”或“追加到当前输入”
- 风格选择细节：
  - 以卡片或分段按钮展示
  - 当前选中态明显
  - 切换风格后，模板列表动态刷新或重新排序
  - 风格展示必须覆盖 PRD 中全部 MVP 枚举：
    - `style_tang_dynasty`：盛唐
    - `style_han_dynasty`：汉代
    - `style_xianxia`：仙侠
    - `style_new_chinese`：新中式
    - `style_gufeng_portrait`：国风人像
    - `style_cinematic`：电影质感
  - 每个风格卡片至少展示：
    - 风格名称
    - 核心描述
    - 是否额外加积分
    - 代表性关键词摘要
- 模板选择细节：
  - 推荐模板优先展示热门和与当前风格最相关的选项
  - 模板卡片展示模板名、用途和额外积分提示
  - 模板展示必须覆盖 PRD 中全部 MVP 枚举：
    - `tpl_oc_avatar`
    - `tpl_dreamgirl_portrait`
    - `tpl_novel_heroine`
    - `tpl_hanfu_photoshoot`
    - `tpl_wallpaper_character`
    - `tpl_xiaohongshu_cover`
    - `tpl_video_cover`
    - `tpl_character_sheet`
  - 每个模板卡片至少展示：
    - 模板名
    - 适用场景
    - 构图特点
    - 是否 `+1` 积分
  - 热门模板区必须区分：
    - 最近爆款
    - 小红书热门
    - 汉服热门
- 比例选择细节：
  - 比例按钮附带用途说明，如头像、壁纸、封面
  - 默认值为 `1:1`
  - 比例选择必须完整覆盖 PRD 中全部枚举：
    - `ratio_square_1_1`：`1:1`，头像、社交封面、小红书配图，`1024x1024`
    - `ratio_portrait_3_4`：`3:4`，半身人像、国风写真，`960x1280`
    - `ratio_portrait_2_3`：`2:3`，全身角色、壁纸、小说角色展示，`1024x1536`
    - `ratio_landscape_4_3`：`4:3`，场景插画、多人构图，`1280x960`
    - `ratio_landscape_16_9`：`16:9`，视频封面、横版头图，`1536x864`
    - `ratio_vertical_9_16`：`9:16`，手机壁纸、短视频封面，`864x1536`
  - 每个比例项展示：
    - 比例值
    - 中文名称
    - 推荐场景
    - 是否额外加价（本期均为 `+0`）
- 参考图上传细节：
  - 支持拖拽或点击上传
  - 上传后显示缩略图、删除按钮、参考模式
  - 最多 3 张
  - 参考图区域必须直接映射 PRD 规则：
    - `reference_image_count` 仅允许 `0/1/2/3`
    - `reference_mode` 包含：
      - `character`：保留人物特征
      - `style`：参考画风
      - `pose`：参考姿势
  - 参考图附加积分展示规则：
    - `0` 张：`+0`
    - `1` 张：`+1`
    - `2` 张：`+2`
    - `3` 张：`+3`
- 质量档与报价区细节：
  - 展示 `普通 / 高清 / 超精细`
  - 实时展示基础消耗、附加消耗、最终积分
  - 需要有“为什么要多花积分”的解释文案
  - 质量档必须映射 PRD 计费枚举：
    - `standard`：`1` 积分
    - `hd`：`2` 积分
    - `ultra`：`3` 积分
  - 报价区必须显式拆开展示：
    - 基础质量积分
    - 风格附加积分
    - 模板附加积分
    - 参考图附加积分
    - 最终积分
  - 报价区必须支持展示 PRD 已确认的典型 case，例如：
    - 普通生成 + 盛唐 + OC头像 + 无参考图 = `1`
    - 高清生成 + 国风人像 + 小红书封面 + 1张参考图 = `4`
- 提交区细节：
  - 主按钮文案固定为 `立即生成`
  - 未登录状态点击主按钮应先拉起手机号验证码登录，再回到原有参数
  - 积分不足时主按钮点击后进入充值引导
- 关键状态：
  - 未登录可填写参数，但提交时拉起手机号验证码登录
  - Prompt 超长时提示裁剪
  - 积分不足时提示充值
  - 上传参考图时显示缩略图和数量限制
  - 模型繁忙时可提示预计等待时间
- 错误态：
  - 上传失败：提示重新上传
  - 内容预审失败：标注敏感原因并引导修改
  - 参数非法：就近提示具体字段
- 响应式要求补充：
  - 移动端参数区可折叠为分组卡片或抽屉
  - 报价区在移动端应固定于底部附近，避免滚动后看不到

### 3.3 登录弹窗/登录页

- Figma 参考：
  - 登录页面：https://www.figma.com/design/0oLoQWIykGOTIvvzeMsQan/%E7%A7%91%E7%A0%94%E7%AE%A1%E7%90%86%E5%B9%B3%E5%8F%B0?node-id=29-2472&t=yow0lQYCugEsx1ml-11
  - 首登开户态参考：https://www.figma.com/design/0oLoQWIykGOTIvvzeMsQan/%E7%A7%91%E7%A0%94%E7%AE%A1%E7%90%86%E5%B9%B3%E5%8F%B0?node-id=29-4095&t=yow0lQYCugEsx1ml-4
- 页面目标：
  - 让用户通过唯一身份入口快速进入生成流程
  - 新用户首次登录时自动开户并领取新手免费次数
- 页面结构：
  - 手机登录表单区
  - 登录按钮
  - 新手奖励说明
  - 找回/帮助提示（如后续需要）
- 手机登录表单：
  - 手机号
  - 验证码
- 交互要求：
  - 仅支持手机号验证码登录
  - 登录成功后返回原始页面和原始参数
  - 如为首次登录手机号，登录成功后自动创建账号
  - 首次登录成功后提示“已获得 10 次免费生成机会”
  - 若是从生成工作台触发，登录后可继续提交
- 状态要求：
  - 登录中
  - 登录成功
  - 登录失败
  - 验证码错误
  - 首次登录开户成功

### 3.4 结果页

- Figma 参考：
  - 绘制中：https://www.figma.com/design/0oLoQWIykGOTIvvzeMsQan/%E7%A7%91%E7%A0%94%E7%AE%A1%E7%90%86%E5%B9%B3%E5%8F%B0?node-id=29-2227&t=yow0lQYCugEsx1ml-11

- 页面目标：
  - 在生成成功后第一时间给用户强正反馈
  - 把“查看 -> 下载 -> 分享 -> 再次生成”串成一条顺畅路径
  - 在失败或审核中时也让用户明确下一步
- 页面入口：
  - 提交生成成功后的自动跳转
  - 作品列表点击进入
- 页面出口：
  - 下载本图
  - 进入分享流程
  - 使用当前参数再次生成
  - 返回作品页或生成工作台
- 页面信息结构：
  - 顶部状态区：成功 / 审核中 / 失败 / 违规
  - 主视觉区：大图预览
  - 操作区：下载、分享、再次生成
  - 参数回顾区：显示所用风格、模板、比例、质量档
  - 推荐区：相关模板或“再试一个相似角色”
  - 参数回顾区必须完整映射本次生成参数：
    - Prompt 文本摘要
    - `style_id`
    - `template_id`
    - `ratio_id`
    - 质量档
    - 参考图数量
    - 最终积分消耗
- 成功态细节：
  - 大图尽量占据页面视觉中心
  - 下载按钮应为最直接操作
  - 分享按钮应展示“生成分享图”或“分享到小红书/微信”
  - 再次生成可复用相同参数并允许微调 Prompt
- generating 态：
  - 展示“AI 正在绘制中...”与预计时间
  - 可选展示阶段式进度文案，如“正在润色服饰细节”
- reviewing 态：
  - 展示审核中提示
  - 告知通常等待时间
  - 不允许提前下载
- failed 态：
  - 明确失败原因分类：模型异常 / 超时 / 网络问题
  - 展示“积分已退回”或“将自动退回”
  - 提供重试入口
- blocked 态：
  - 提示内容不符合平台规则
  - 不展示违规图片
  - 提供返回修改 Prompt 的入口
- 分享区细节：
  - 分享文案、分享图、回流链接都需可预览
  - 优先突出小红书分享场景
  - 分享渠道必须覆盖：
    - 小红书
    - 微信
    - QQ
    - 微博
  - 分享文案区要支持类似：
    - “我在唐绘生成了专属盛唐角色”
- 响应式要求补充：
  - 移动端操作按钮固定底部
  - 大图预览在移动端优先，不要被参数回顾区挤压
- 实现边界：
  - 结果页不能只显示图片，必须承担分享和再生成承接职能

## 4. 交互流程

### 4.1 用户主流程

1. 游客进入首页
2. 浏览风格区、案例区、情绪化模板入口
3. 点击“立即生成”进入生成工作台
4. 输入 Prompt，选择风格、模板、比例、参考图
5. 查看积分报价
6. 点击提交，若未登录则先进行手机号验证码登录
7. 首次登录成功后获得免费次数并返回当前流程
8. 进入生成中状态
9. 查看结果页，选择下载、分享或再次生成

### 4.2 分享回流流程

1. 用户在结果页点击分享
2. 系统展示分享图和分享文案
3. 用户选择分享渠道
4. 新用户通过链接进入首页
5. 新用户首次登录并获得新手免费次数
6. 新用户进入首次生成

### 4.3 管理员流程

1. 管理员登录后台
2. 查看用户管理列表
3. 进入用户详情维护账户
4. 进入模型配置中心维护模型
5. 进入模型监控页查看状态与告警

## 6. 视觉约束

- 整体视觉方向：东方幻想、女性向、精致但不厚重
- 首页重点：Banner 要有明显视觉中心，避免普通工具站感
- 色彩语义：
  - 主色建议：偏东方金、胭脂红、青黛、米白体系
  - 成功态：柔和绿色
  - 危险态：高辨识红色
  - 禁用态：低饱和灰
- 卡片风格：统一圆角、轻阴影、适度留白
- 图像区：优先大图视觉冲击，避免缩略图堆砌
- 管理后台：以信息清晰为主，降低装饰性

## 7. 表单与校验规则

- Prompt：
  - 必填
  - 超过 300 字不允许提交
- 风格：必选
- 模板：可选，但建议默认推荐
- 比例：必选，默认 `1:1`
- 参考图：
  - 最多 3 张
  - 需校验图片格式和大小
- 登录表单：
  - 手机号格式校验
  - 验证码必填
- 管理后台：
  - 模型配置表单需校验 `base_url`、`model_name`、`timeout_seconds`

## 8. 响应式要求

- 桌面端：
  - 首页可采用双列或大首屏布局
  - 生成工作台可采用左右分栏
- 平板端：
  - 参数区折叠为上下结构
  - 卡片改为两列
- 移动端：
  - 首页改为单列滚动
  - 参数面板改为折叠/抽屉
  - 结果页大图优先，操作按钮固定底部
  - 后台页只要求基础可访问，优先保证桌面端体验

## 9. 文案与语气

- 面向用户端：
  - 语气要温柔、鼓励、带一点幻想感
  - 避免过度技术化表达
- 面向管理后台：
  - 文案直接、清晰、无歧义
- 失败提示：
  - 明确原因
  - 给出下一步操作
- 分享文案：
  - 以“专属角色”“人设生成”“国风幻想身份”为核心语义
