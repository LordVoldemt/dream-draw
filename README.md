# 绘梦

一个面向女性向国风角色、梦女与 OC 创作场景的 Web 应用原型，采用 `Vue 3 + Element Plus + Python 3.11` 实现。

## 当前实现范围

- 用户端：首页、生成工作台、手机号验证码登录、首登奖励页、作品页、结果页、积分充值页
- 管理端：管理员登录、用户管理、用户详情、模型配置中心、模型状态监控
- 后端能力：手机号验证码登录、积分报价、生成任务、作品落库、分享、支付订单、后台用户维护、模型配置与监控

## 目录结构

```text
src/        前端用户端与管理端页面
backend/    FastAPI 风格 API 与 SQLite 仓储实现
shared/     前后端共享枚举与产品目录
tests/      后端集成测试与前端单元测试
```

## 本地开发

### 前端

```bash
npm install
npm run test
npm run build
```

### 后端

```bash
python -m pip install -r backend/requirements.txt
pytest tests/backend -q
```

## 已验证链路

- 游客浏览首页 -> 手机号登录 -> 提交生成 -> 查看结果 -> 查看作品
- 结果页分享 -> 新用户登录 -> 首次生成
- 管理员登录 -> 查看用户 -> 维护积分/状态 -> 查看模型配置 -> 查看模型监控
- 风控与兜底：游客禁止生成、每日次数限制、IP 限流、重复 Prompt 防刷、失败退款、主模型不可用时切备用模型

## 注意事项

- 当前后端使用 SQLite 与本地默认 provider 种子，便于单机开发验证
- 当前“绘制中”页面已实现，但主链路为了联调效率，任务创建后会立即进入最终状态
- 生产环境接入真实短信、支付、对象存储和模型网关时，仍建议按 `.adpp/changes/.../design.md` 继续替换 mock/本地实现
